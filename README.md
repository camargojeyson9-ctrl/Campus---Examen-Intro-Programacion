# Campus---Examen-Intro-Programacion.


En el siguiente repositorio se aloja un cajero automático con las siguientes funciones.

Consulta Saldo actual del usuario.
Deja ingresar un deposito de dinero, imprime confirmación y te da el nuevo saldo, de acuerdo al saldo anterior mas el nuevo ingreso.
Deja retirar un dinero, imprime confirmación y te da el nuevo saldo, de acuerdo al saldo anterior menos el nuevo retiro.
Da opción de salir colocando 4 o 0.
Si colocamos una opción invalida el programa retorna nuevamente el menú.
